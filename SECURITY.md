# Security policy

Please report vulnerabilities privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab, choose **Report a vulnerability**, and describe the problem, the mod affected and how to reproduce it. You will get a reply as soon as I can manage, normally within a week.

In scope: any mod that lets a secret slip past `secret-guard`, restores or deletes the wrong files in `auto-checkpoint`, runs commands it should not, or sends data off the machine without saying so. Please do not include real secrets in a report.

Only the latest release is supported.
